<h1>자동차 경주</h1>

## 기능 요구사항 체크리스트

### 입력/검증
- [x] 각 자동차에 이름을 부여한다. (쉼표`,`로 구분).
    - [x] 이름은 **5자 이하**여야 한다.
    - [x] 공백/빈 문자열, 5자 초과 등 **잘못된 값은 `IllegalArgumentException`** 발생 → 프로그램 종료
- [x] 이동(시도) 횟수를 입력받는다.
    - [x] 숫자가 아님/음수 등 **잘못된 값은 `IllegalArgumentException`** 발생 → 프로그램 종료

### 게임 로직
- [x] 주어진 횟수마다 자동차는 **전진** 또는 **멈춤**한다.
- [x] **무작위 값(0~9)**을 구한 후 **4 이상이면 전진**한다.
- [x] 전진/멈춤 판단은 **자동차별·라운드별 독립**적으로 수행한다.

### 출력
- [x] 전진 결과를 **자동차 이름과 함께 출력**한다. (예: `pobi : ---`)
- [x] 모든 라운드 종료 후 **우승자 출력**
    - [x] **공동 우승** 시 **쉼표`,`로 구분** (예: `최종 우승자 : pobi,woni`)

### 예외/종료
- [x] 잘못된 입력 시 **즉시 `IllegalArgumentException`** 발생 및 **애플리케이션 종료**
- [x] 예외 메시지는 사용자 친화적으로 작성

## 프로그래밍 요구 사항
- [x] JDK 21 버전에서 실행 가능해야 한다.
- [x] 프로그램 실행의 시작점은 Application의 main()이다.
- [x] build.gradle 파일은 변경할 수 없으며, 제공된 라이브러리 이외의 외부 라이브러리는 사용하지 않는다.
- [x] 프로그램 종료 시 System.exit()를 호출하지 않는다.
- [x] 프로그래밍 요구 사항에서 달리 명시하지 않는 한 파일, 패키지 등의 이름을 바꾸거나 이동하지 않는다.
- [x] 자바 코드 컨벤션을 지키면서 프로그래밍한다.
- [x] 기본적으로 Java Style Guide를 원칙으로 한다.
